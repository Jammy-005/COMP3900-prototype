# Non-planar Slicer for Robotic 3D Printing

COMP3900 project 132. An open-source library that takes a 3D model plus print
parameters and produces multi-axis, non-planar toolpaths, exported as ABB RAPID
and KUKA KRL programs.

**Status:** pre-code. The repository currently holds planning documents only.
